# Roblox Ragdoll Toggle Script

This script toggles ragdoll for the player when the 'Q' key is pressed. Pressing 'Q' again stops the ragdoll. It is designed for Roblox games and requires a Humanoid and a character model to function correctly.

## Installation

1. Open Roblox Studio.
2. Create a new script in ServerScriptService.
3. Copy and paste the contents of `RagdollToggleScript.server.lua` into the script.
4. Save the script.

## Usage

- Press the 'Q' key to toggle ragdoll for the player.
- Press the 'Q' key again to stop the ragdoll.
